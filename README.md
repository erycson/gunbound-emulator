Python 3.11

## Instalando
Se um ambiente virtual do python não existir, execute:

```bash
python -m venv .
```

Depois, ative-o e instale as bibliotecas utilizadas pelo sistema

```
python -m venv .
./Scripts/activate
pip install -r requirements.txt
```
